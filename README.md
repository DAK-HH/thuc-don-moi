# Thực đơn gia đình

Ứng dụng web nhỏ (PWA) gợi ý thực đơn cho cả nhà. Chạy hoàn toàn trên trình duyệt, dữ liệu nhập được lưu ngay trên máy của bạn.

## Đưa lên GitHub Pages
1. Tạo repository mới trên github.com (ví dụ `thuc-don-gia-dinh`).
2. Chọn **Add file → Upload files**, kéo toàn bộ file trong thư mục này vào, bấm **Commit changes**.
3. Vào **Settings → Pages**, ở *Branch* chọn `main` và thư mục `/ (root)`, bấm **Save**.
4. Sau 1–2 phút, trang chạy tại `https://<tên-github>.github.io/thuc-don-gia-dinh/`.

## Cài như một ứng dụng
- Máy tính (Chrome/Edge): bấm biểu tượng cài đặt ở thanh địa chỉ.
- Điện thoại: mở trang, chọn **Thêm vào Màn hình chính** (iPhone: nút Chia sẻ trong Safari).

Số liệu mặc định chỉ là ví dụ, hãy sửa lại trong app. Chỉ là ước tính tham khảo, không thay thế tư vấn của bác sĩ hay chuyên gia dinh dưỡng.
